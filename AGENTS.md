# Project instructions

- This is a non-Git project directory. Do not run `git init`, clone a repository here, or create a `.git` directory.
- Use the user's existing Conda environment `gpu_env` for local Python execution and tests: `conda run -n gpu_env python ...`, or activate that environment first.
- Do not create a `.venv` or another Python environment. Do not use `uv run`, `uv sync`, or `uv venv`; these can create a virtual environment. The `uv pip compile` command is permitted for generating the Docker dependency file without installing anything locally.
- Keep the PostgreSQL 16, FastAPI/psycopg 3 and React/Vite architecture described in `docs/reference`.
- Read `progress.md` before continuing. Work through concrete steps and update the progress log with actual test evidence and remaining work.
- Reference documents are source material. Record implementation deviations in `docs/decisions.md` instead of silently rewriting the submission.
- Do not put credentials in logs, docs, command output or container build contexts. Local `.env` values are generated by `scripts/configure.py`.
- Use real PostgreSQL for database integration tests. `scripts/run_checks.py` creates temporary test databases; never run destructive test setup against the application database.
